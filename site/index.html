功能

面向日常数据库运维与开发，重点在「连得上、看得清、改得动」。

多数据库与免装驱动

  • MySQL / PostgreSQL / Oracle / OceanBase / 任意 JDBC
  • Oracle 免装 OCI（内置 go-ora 桥接）
  • OceanBase Oracle 模式走官方 JDBC 驱动

连接与凭据

  • 分组文件夹、多级嵌套、拖拽归类、搜索
  • 密码存 Windows 凭据管理器，配置文件不留明文
  • 配置导入导出（可口令加密）；支持 DBeaver / Navicat / PL/SQL Developer 导入

对象浏览与编辑

  • 表 / 视图 / 索引 / 序列 / 函数 / 存储过程 / 触发器
  • 表结构、索引、源码查看（Tab 形式）与变更预览执行
  • 对象状态角标（Oracle INVALID / UNUSABLE）与一键重编译

SQL 编辑器

  • CodeMirror 6，方言高亮 + 表/列自动补全
  • 快捷指令、自定义美化器、执行计划
  • 全部 / 选中 / 当前行执行，多语句多结果集

结果集

  • 大结果自动虚拟滚动，分页续拉
  • 排序、筛选、值筛选、统计行、列宽持久化
  • 多选复制、导出 Excel / SQL / CSV / TXT / JSON
  • 结果编辑（预览 DML + 撤销重做 + 事务提交）

会话与锁

  • 活动会话 / 阻塞链 / 锁等待视图
  • 取消查询、终止会话（Oracle 双模式、批量）
  • 会话详情与 CSV 导出

界面与效率

  • 工作台四区停靠 + 悬浮窗、左右/上下分屏
  • 命令面板 Ctrl+K、查询历史、快捷指令
  • 浅色 / 深色主题，中文 / English 界面

数据与隐私

  • 数据库连接全部直连，不经任何中转服务器
  • 不上传连接信息、SQL 或结果集
  • 唯一的外联是「检查更新」时读取 GitHub 公开发布信息

系统要求与说明

仅支持 Windows 桌面端（x64）。

运行环境

  • Windows 10 1803+ / Windows 11（x64）
  • WebView2 运行时（Win11 与较新 Win10 已内置）
  • 仅在使用 OceanBase Oracle 模式时需要 JRE 21+

安装包

  • .msi：标准 MSI 安装包
  • -setup.exe：NSIS 安装包
  • 两者功能一致，任选其一即可，无需共存

更新方式

  • 应用内「帮助 → 检查更新」查询 GitHub 上的最新发布
  • 只做提示，不自动下载、不静默安装
  • 下载安装包覆盖安装即可，配置与连接保持不变

已知限制

  • OceanBase Oracle 模式需填 用户@租户，Schema 留空
  • OceanBase 连接需直连 OBServer(2881) 或 OBProxy(2883)
  • macOS / Linux 暂未提供构建
